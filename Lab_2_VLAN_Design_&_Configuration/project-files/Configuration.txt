⚙️ Complete Configuration
SW1 Configuration (Distribution Switch)
text
enable
configure terminal
hostname SW1

vlan 10
 name Engineering
vlan 20
 name Marketing

interface GigabitEthernet0/1
 description TRUNK-TO-SW2
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 no shutdown

interface GigabitEthernet0/2
 description ACCESS-PC3-VLAN20
 switchport mode access
 switchport access vlan 20
 switchport port-security
 switchport port-security maximum 1
 switchport port-security violation shutdown
 no shutdown

interface Vlan10

🔍 Troubleshooting Section
Issue 1: PC cannot ping gateway

Check	Command	Solution
VLAN exists?	show vlan brief	Create VLAN
Port in correct VLAN?	show interfaces status	switchport access vlan X
SVI enabled?	show ip interface brief	no shutdown on SVI
IP configured?	show run interface VlanX	Assign IP address
Issue 2: Trunk not passing traffic

text
show interfaces trunk
show interfaces GigabitEthernet0/1 trunk
show interfaces GigabitEthernet0/1 switchport
Common solutions:

Ensure both ends in trunk mode

Check allowed VLAN list

Verify encapsulation matches (dot1q)

Check native VLAN matches

Issue 3: Inter-VLAN routing failure

text
show ip route
show ip cef
show interfaces Vlan10
show interfaces Vlan20
Issue 4: MAC address learning issues

text
clear mac address-table dynamic
show mac address-table count
show mac address-table aging-time
🌐 Real-World Use Case
Enterprise Scenario:
A mid-sized company with 500+ employees implementing network segmentation:

VLAN 10: Engineering (Development, Testing, Build Servers)

VLAN 20: Marketing (Web Servers, CMS, Design Tools)

VLAN 30: HR (Sensitive Employee Data)

VLAN 40: Finance (Financial Systems)

VLAN 50: Guest WiFi (Internet Only)

Benefits:

Security isolation between departments

Broadcast traffic containment

Easier network management

Quality of Service (QoS) per VLAN

Compliance with data protection regulations

📝 Key Learning Points
VLAN Fundamentals

Logical segmentation of Layer 2 network

4094 possible VLAN IDs (1-4094)

VLAN 1 is default native VLAN

Port Types

Access Port: One VLAN, untagged frames

Trunk Port: Multiple VLANs, tagged frames

Native VLAN: Untagged frames on trunk

VLAN Trunking Protocol (VTP)

VTP modes: Server, Client, Transparent

VTP pruning for bandwidth optimization

Inter-VLAN Routing Methods

Router-on-a-stick (external router)

SVI on Layer 3 switch

Using physical router interfaces

VLAN Best Practices

Use VLANs 1-1000 for normal usage

Reserve VLANs 1002-1005 for special functions

Enable port-security on access ports

Disable unused ports (shutdown)

Use descriptive VLAN names
